# Pixel

Pixel 是一个使用 Rust 和 [Slint](https://slint.dev/) 编写的轻量级像素画编辑器。它可以绘制像素图、切换颜色、导入图片、保存项目，并将作品导出为 PNG。

## 功能

- 铅笔、橡皮擦和取色器
- 鼠标拖动连续绘制，快速移动时自动补齐中间像素
- RGB 颜色调节和 16 色调色板
- 可显示或隐藏像素网格
- 撤销、重做和清空画布
- 32×32、64×64、128×128 预设画布
- 支持 32–256 的自定义正方形画布尺寸
- 导入常见图片并缩放到当前画布
- 保存和打开 Pixie JSON 项目
- 使用最近邻缩放导出清晰的 PNG

## 运行环境

- Rust stable
- Cargo
- Windows、Linux 或 macOS

## 运行

```bash
cargo install --git https://github.com/23jdd/Pixel
pixel
```


## 使用方法

### 绘制

- 鼠标左键：绘制或擦除
- 鼠标右键：从画布取色
- `Pencil`：使用当前颜色绘制
- `Eraser`：将像素恢复为透明
- `Picker`：点击像素并将其设为当前颜色
- `Grid`：显示或隐藏网格

### 颜色

可以直接选择右侧调色板中的颜色，也可以使用 R、G、B 滑杆创建自定义颜色。

### 画布尺寸

右侧 `CANVAS SIZE` 面板提供 32、64 和 128 三种预设尺寸。也可以输入 32–256 之间的整数，然后按 `Enter` 或点击 `Apply` 创建自定义正方形画布。

切换尺寸会创建新的透明画布，并清除当前撤销记录。旧版 16×16 Pixie 项目仍然可以打开。

### 项目文件

- `New`：使用当前尺寸创建空白项目
- `Open`：打开 `.json` Pixie 项目
- `Save`：保存到当前项目文件
- `Save As`：另存为新的项目文件
- `Read`：导入图片并缩放到当前画布尺寸

项目文件使用可读的 JSON 格式保存画布尺寸和每个像素的 RGBA 值。

### 导出 PNG

点击 `Export PNG` 将作品导出为 PNG。每个逻辑像素会放大为 16×16 个图片像素，因此：

| 画布尺寸 | 导出尺寸 |
| --- | --- |
| 32×32 | 512×512 |
| 64×64 | 1024×1024 |
| 128×128 | 2048×2048 |

透明像素会保留透明通道，导出过程不会进行平滑插值。


## 项目格式

Pixie 项目当前使用 `pixie-1` 格式：

```json
{
  "format": "pixie-1",
  "width": 32,
  "height": 32,
  "pixels": [
    [255, 204, 102, 255]
  ]
}
```

`pixels` 按从左到右、从上到下的顺序保存，每项依次为红、绿、蓝、透明度。
